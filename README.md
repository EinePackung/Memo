# Memo Web Application

A simple memo web application built to practice full-stack development, REST APIs, and SQL database integration.

## Motivation

This project was created to practice both back-end and front-end development, and to learn how to connect a web application with a SQL database.

## Goals

- Create, read, update, and delete memos
- Build a REST API
- Store memo data in a SQL database
- Add user identification

## Features

- Add memo
- Read memo list
- Edit memo
- Delete memo
